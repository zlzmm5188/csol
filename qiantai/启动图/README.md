# 星空锁屏 - 高清动态壁纸应用

## 应用简介

星空锁屏是一款精美的移动端动态壁纸应用，专为追求个性化和美观的用户设计。应用提供高清星空主题，配合流畅的动画效果，让你的手机锁屏界面焕然一新。

## 主要特性

- ✨ **高清星空背景** - 精心设计的星空粒子动画效果
- 🎨 **个性化文字** - 支持自定义品牌文字和标语
- 📱 **移动端优化** - 专为手机屏幕优化，流畅运行
- 🌈 **动态光效** - 多层次光晕和渐变效果
- 🔒 **隐私保护** - 无广告，无数据收集
- 🚀 **轻量快速** - 体积小，加载快

## 技术栈

- React 18
- TypeScript
- Tailwind CSS
- Vite

## 应用分类

工具 / 个性化 / 壁纸美化

1. 在移动设备上打开应用
