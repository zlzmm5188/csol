# 星空锁屏壁纸应用 - 产品说明文档

## 一、应用基本信息

**应用名称：** 星空锁屏 (Starry Lockscreen Wallpaper)
**应用类型：** 工具类 / 个性化 / 壁纸美化
**版本号：** v1.0.0
**开发商：** Providence Design Studio
**发布日期：** 2025年1月
**适用平台：** 移动端（iOS、Android）

## 二、应用功能说明

### 主要功能

1. **动态星空壁纸**
   - 提供高清星空背景主题
   - 150+动态星光粒子效果
   - 流畅的动画渲染（60fps）
   - 多层次光晕和渐变效果

2. **个性化设置**
   - 支持自定义显示文字
   - 可配置品牌标识
   - 支持多种文字样式

3. **设备优化**
   - 针对不同品牌手机进行性能优化
   - 智能识别设备型号并调整动画参数
   - 确保在各种设备上流畅运行

### 技术特点

- 基于React 18 + TypeScript开发
- 使用Tailwind CSS实现响应式设计
- PWA（渐进式Web应用）技术支持
- 硬件加速动画，性能优异
- 纯前端实现，无后端服务器

## 三、设备兼容性

### 支持的设备品牌

- **iOS系列：** iPhone、iPad
- **华为系列：** HUAWEI、HONOR、HarmonyOS设备
- **小米系列：** MI、Redmi、Xiaomi
- **OPPO系列：** OPPO全系列
- **vivo系列：** vivo全系列
- **三星系列：** Samsung Galaxy系列
- **其他品牌：** realme、OnePlus、魅族、中兴等

### 屏幕适配范围

- **手机屏幕：** 宽度320-500px，高度500-1100px
- **平板屏幕：** 宽度600-1400px，高度800-2000px
- **像素密度：** 支持1.5x至4x的设备像素比

### 平台限制说明

**重要：本应用仅支持移动端设备**

由于应用专为移动端触摸交互和小屏幕优化设计，在桌面浏览器环境下会显示降级界面。这是正常的设计行为，旨在：
- 确保用户在最佳环境下体验应用
- 防止桌面端性能浪费
- 引导用户使用移动设备访问

## 四、隐私与安全

### 数据收集政策

**本应用不收集任何用户数据，包括但不限于：**
- 个人身份信息

## 五、代码架构说明

### 目录结构

```
app-splash-screen/
├── public/              # 静态资源
│   ├── logo.png        # 应用图标
│   ├── manifest.json   # PWA配置
│   ├── about.html      # 应用介绍页
│   └── privacy.html    # 隐私政策页
├── src/
│   ├── App.tsx         # 主应用组件
│   ├── main.tsx        # 应用入口
│   └── index.css       # 动画样式
├── index.html          # HTML模板
├── package.json        # 项目配置
└── README.md           # 项目说明
```

### 核心代码说明

**App.tsx - 主应用逻辑**
1. 设备检测模块：识别用户设备类型并优化显示
2. 星空粒子生成器：创建150个动态星光效果
3. 动画渲染引擎：控制光晕、浮动等动画效果
4. 响应式布局：适配不同屏幕尺寸

**index.css - 动画定义**
- fadeIn：淡入动画
- float：浮动动画
- glow：光晕脉动动画
- logo：logo旋转动画
- waveLetter：文字波浪动画
